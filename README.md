# Лабораторная работа 5 - Проектирование модели управления версиями ПО, конфигурациями и непрерывной поставкой

## Обзор

Работа посвящена инфраструктуре как коду: управление контейнерами через
Terraform, конфигурация серверов через Ansible и развёртывание приложения
в локальном кластере Kubernetes из трёх нод.

Вариант 10.

## Использование

- `task1/` - семь учебных шагов Terraform Get Started на провайдере
  Docker: создание и изменение инфраструктуры, переменные, data source,
  output'ы, destroy. Конфигурация и команды - в `task1/README.md`.
- `task2/` - Ansible: инвентарный файл нод kind-кластера (подключение
  через `community.docker.docker`), ad-hoc команды и два плейбука
  (подготовка нод, установка и управление nginx). Команды и результаты -
  в `task2/README.md`.
- `task3/` - кластер Kubernetes из трёх нод на kind, созданный Terraform,
  и деплой в него приложения «салон красоты» из лабораторной работы 1
  через Ansible-плейбук. Манифесты и порядок запуска - в
  `task3/README.md`.
- `docs/report.md` - отчёт с описанием выполнения и ответами на
  контрольные вопросы.
